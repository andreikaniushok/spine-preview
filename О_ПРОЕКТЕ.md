# Spine Preview (spine-lab) — описание проекта

Документ описывает **текущую реализацию**: слои SOLID, назначение папок, роль файлов и потоки данных. Краткий README — [README.md](README.md).

---

## 1. Что это

Клиентское SPA для локального просмотра и анализа анимаций [Spine](http://esotericsoftware.com/) **4.2**.

- Нет бэкенда, `.env`, БД.
- Файлы (`.json`/`.skel` + `.atlas` + текстуры) обрабатываются в браузере.
- Стек: React 19 + TypeScript + Vite 8 + PixiJS v8 + `@esotericsoftware/spine-pixi-v8` / `spine-core`.

---

## 2. Карта папок (с первого взгляда)

```
src/
  app/          ← оболочка React (main, App, CSS)
  ui/           ← экраны и кнопки (панели + ui/components)
  hooks/        ← связка UI ↔ сервисы (useSpinePreview)
  i18n/         ← тексты интерфейса

  pixi/         ← PixiJS (canvas, pan/zoom) — без React
  spine/        ← Spine (загрузка моделей + playback) — без React
  import/       ← импорт паков с диска → бандлы — без React/Pixi
  metrics/      ← FPS + бенчмарк — без React
  analytics/    ← отчёты (atlas / cost / stats) — без React

  types/        ← общие TypeScript-типы для всех слоёв
```

| Хочу найти… | Открываю |
|-------------|----------|
| Экран, layout, стили | `app/` |
| Кнопки, панели, оверлеи | `ui/` |
| Переиспользуемые кнопки/progress | `ui/components/` |
| Логику «склейки» React | `hooks/` |
| Canvas Pixi, pan/zoom | `pixi/` |
| Загрузку Spine, play/skin | `spine/` |
| Импорт `.json/.skel + .atlas` с диска | `import/` |
| FPS / бенчмарк | `metrics/` |
| Таблицы анализа | `analytics/` |
| Строки UI | `i18n/` |
| Общие типы данных | `types/` |

У модульных папок есть **`index.ts`** — публичный API. Предпочтительно:

```ts
import { PixiApp, SceneController } from "../pixi";
import { SpineManager, AnimationController } from "../spine";
import type { SpineModel } from "../types";
```

## 3. Слои и SOLID

```
ui / app          (React presentation)
       ↓ props / callbacks
hooks             (оркестратор, единственная «склейка»)
       ↓
pixi | spine | import | metrics    (OOP services)
       ↘
analytics                          (pure functions)
       ↕
types                              (общие типы)
```

| Принцип | Как соблюдается |
|---------|-----------------|
| **S**ingle responsibility | Одна папка ≈ одна зона ответственности |
| **O**pen/closed | Новые фичи — в своей папке, без размазывания по UI |
| **L**iskov | Сервисы за интерфейсами (`ISpineManager`, `IBenchmarkRunner`, …) |
| **I**nterface segregation | Узкие API в `index.ts`, UI не тянет Pixi |
| **D**ependency inversion | UI зависит от `viewModel`/`actions` и типов; Pixi/Spine только в `hooks` + сервисных папках |

**Жёсткие правила:**

1. `ui/`, `app/` — **без** импортов `pixi.js` / Spine runtime.
2. `pixi/`, `spine/`, `import/`, `metrics/`, `analytics/` — **без** React.
3. `analytics/` — без Pixi `Application` (только `spine-core` / чистые данные).
4. Оркестрация ticker / state — только в `hooks/useSpinePreview.ts`.

## 4. Boot

1. `index.html` → `/src/app/main.tsx`
2. `StrictMode` → `I18nProvider` → `App`
3. `App` → `useSpinePreview()`
4. Хук один раз: `PixiApp` → `SceneController` → `SpineManager` + `AnimationController` + `PerformanceMonitor` + `BenchmarkRunner` + ticker

## 5. Папки и файлы подробно

### `src/app/` — оболочка React

| Файл | Роль |
|------|------|
| `main.tsx` | `createRoot`, StrictMode, I18nProvider |
| `App.tsx` | Layout, DnD, toggles metrics/analytics |
| `App.css` | Стили UI |
| `index.css` | Глобальный reset |

### `src/ui/` — интерфейс

| Файл / папка | Роль |
|--------------|------|
| `AppHeader.tsx` | Тема, язык, Analytics / Metrics |
| `ControlPanel.tsx` | Модели, анимации, playback, skin, alpha, debug |
| `PerformanceReportPanel.tsx` | Отчёты + baseline; внутри `BenchmarkPanel` |
| `BenchmarkPanel.tsx` | UI бенчмарка |
| `components/` | `Button`, `FieldRow`, `ProgressBar`, `StatGrid` |

### `src/hooks/` — связка

| Файл | Роль |
|------|------|
| `useSpinePreview.ts` | Refs на сервисы, state, actions, viewModel, hotkeys, ticker |

### `src/pixi/` — рендер

`PixiApp.ts`, `SceneController.ts`

### `src/spine/` — Spine

`SpineManager.ts` (load/registry), `AnimationController.ts` (play/pause/skin/…)

### `src/import/` — импорт паков с диска

`SpineBundleParser.ts` — из `FileList` (кнопка «выбрать файлы» или drag-and-drop) собирает `SpineAssetBundle[]` (скелет + atlas + текстуры по имени). Это не UI DnD, а парсер списка файлов.

### `src/metrics/` — метрики

`PerformanceMonitor.ts` (FPS), `BenchmarkRunner.ts` (сэмплинг бенчмарка)

### `src/analytics/` — анализ

`atlasAnalysis.ts`, `spinePerformanceReport.ts`, `benchmarkStats.ts`, `performanceBaseline.ts`

### `src/types/` — типы

`spine.ts` — `SpineAssetBundle`, `SpineModel`, `PerformanceSnapshot`, `BenchmarkResult`, `BenchmarkUiState`, `PlaybackMode`

Это **не** бизнес-логика, а общие описания данных, чтобы `ui`, `spine`, `metrics` и др. говорили на одном языке.

### `src/i18n/` — строки

`en.ts` (+ `MessageKey`) / `pl.ts` / `ru.ts`, provider, `useI18n`

## 6. Потоки данных

### Загрузка

```
FileList
  → import.SpineBundleParser.parseBundles
  → SpineAssetBundle[]
  → spine.SpineManager.loadBundle
  → hooks state
  → AnimationController.bind
  → SceneController.center*
```

### Кадр

```
Pixi ticker (в hooks)
  ├─ metrics.PerformanceMonitor → setMetrics (~120 ms)
  ├─ каждые 36 кадров → atlasLiveTick → analytics.attachAtlasRenderPasses
  └─ metrics.BenchmarkRunner.tick → BenchmarkUiState
```
